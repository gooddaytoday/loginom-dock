# Loginom Dock 0.1.0-rc.6

RC6 опубликован 14 сентября 2026: [GitHub Release](https://github.com/kartamyshev-dev/loginom-dock/releases/tag/loginom-dock%400.1.0-rc.6).
Клиентский source/tag: `0df6da8246be905445f1c127e57755b9379ac7ce`.
Все пять публичных файлов скачаны и проверены на VPS; соответствующие bytes/SHA
перенесены в `landing/release.json` только после этого подтверждения.

Покрыто14типов: Импорт текста, Параметры полей, Фильтр строк, Слияние,
Объединение, Калькулятор, Группировка, Сортировка, Замена, Дубликаты, Дата и время,
Заполнение пропусков, Свёртка столбцов, Экспорт текста. Поддержка относится к
принятым режимам подпланов, а не всем возможностям Loginom.

Приёмка: три совместных сценария;1819source/1821packaged client checks с1SKIP;
финальные66проверок готового Linux-комплекта; native Mac install/rollback/reinstall;
настоящий Hermes Sol/low с @file49байт, один Sales, точные3строки, сохранение,
независимое открытие исходного GUID и native close/logout обоих сеансов.
Полные результаты: [обычная установка](rc-public-installation-2026-09-14.md),
[совместная приёмка](rc-combined-verification-2026-09-14.md).

На этом Mac Codex и Hermes обновлены до `0.1.0-rc.6-b85bccf2723b`.
Новые сессии используют финальный клиент; уже работающие сохраняют прежние pins.
Для работающего Hermes gateway требуется перезапуск, как указано установщиком.

Ограничения: новая native GUI-проверка Linux/Windows отложена по явному решению
пользователя; Codex native composer event отдельно не воспроизводился, проверены
его контракт и scripted передача; XLSX/JSON-обработчиков нет; вложения мессенджеров
не проверены; оптимизация точного чтения отложена.

Слияние и обычный push main дополнительно подтверждены пользователем14сентября.
До fast-forward сохранены и проверены19локальных незавершённых файлов; все
локальные изменения восстановлены. Прежний remote main7317cc57 был предком,
force push не использовался. Private checkpoint: `.dock/rc-release-20260914/main-local-checkpoint`.

Первая GitHub-загрузка и отдельный повтор прервались на сетевом пути Mac.
После проверки отсутствия первого Release создан черновик, пять файлов переданы
через временный loopback SOCKS/SSH к VPS с end-to-end HTTPS. GitHub credentials
на VPS не копировались; туннель закрыт. Публикация завершена после совпадения
серверных digest/size и затем независимого публичного download/hash read-back.

Обновление сайта: контент и manifest подготовлены; серверная сборка, визуальная
проверка и Caddy-only переключение выполняются следующим этапом. Принятые
клиентские архивы при изменении сайта не пересобираются.
