# Исследование дизайна Loginom benchmark — 10 сентября 2026

Статус: исследование завершено, цельный черновик подготовлен для ревью.
Реализация benchmark, модельные прогоны и изменения SUT не выполнялись.
По последующему прямому поручению пользователя установлен и проверен
диагностический Playwright MCP для Chrome.

## Контракт работы

- Источник требований: `rl-benchmark.md` и текущий запрос пользователя.
- Используется `brainstorming`, но требования пользователя приоритетнее:
  цельное ревью, только существенные развилки, итоговый файл
  `evals/docs/plans/2026-09-10-loginom-benchmark-design.md`, остановка без
  `writing-plans` и реализации.
- Все новые материалы этой задачи находятся в `evals/`. Исключение, необходимое
  для отдельно запрошенного подключения MCP: локальная регистрация сервера
  в `.codex/config.toml`, с сохранением существующего OpenViking.
- Исходный HEAD: `dee1d210`; до работы были незакоммиченные чужие файлы
  `rl-benchmark.md`, `docs/loginom-dock/local-openviking-check.md`,
  `scripts/openviking-workspace-mcp.mjs`. Они не изменяются.
- TypeScript, недельный MVP, первый полный цикл за 1–2 дня, ориентир 3×3,
  один последовательный профиль; Codex предпочтителен. Эти решения не
  требуют повторного обсуждения.

## Выполненные проверки

- Прочитаны `AGENTS.md`, исходное задание, актуальное начало handoff/status,
  индекс подпланов, действующий план, релевантные разделы архитектуры и операций.
- Актуальный индекс подтверждает source runtime подпланов 01–04; 05–10 planned.
  Подтверждения прошлых приёмок не являются новой проверкой этого хоста.
- Существующий `calculator_node_acceptance.py` связан с конкретным goal,
  четырьмя node operations, формулами и одной сессией. Нельзя выдать его
  за универсальный независимый verifier нового benchmark без адаптации.
- `client/lib/session.mjs` поддерживает Linux, требует Node 24.19.0,
  отдельный профиль, visible Chromium `--start-maximized` и `viewport:null`.
  Mac-only ограничение обнаружено у старого acceptance launcher.
- В `client/lib/archive.mjs` capture gated по активации и редактируется до
  очереди; память self может записываться. Это требует ограничения чтения
  архивов/памяти между измеряемыми попытками, а не только нового browser profile.
- Независимые субагенты изучили eval-платформы/skills, соседние репозитории,
  Codex/Hermes и изоляцию; детали в соседних исследовательских записках.

## Память

OpenViking health вернул healthy. Поиск релевантного Experience в
`viking://~/memories/experiences` не дал совпадений; это не ошибка памяти.
Чтение конкретной записи kiselev первоначально дважды отклонила автоматическая
проверка разрешений. Пользователь явно разрешил точный URI, после чего чтение
прошло. Учтены прежние выводы о разделении ролей, технической изоляции и
независимом результате; содержание памяти не считается операционной инструкцией.
Память не изменялась и документы туда не публиковались.

## Живой UI: первоначальное ограничение устранено

Встроенный браузер не открыл документированный URL
`http://logi-test-plan.bg.local/app/?testable=true`: `ERR_BLOCKED_BY_CLIENT`.
Пользователь затем сообщил, что URL открылся у него в Chrome. Повторный inventory
CUA показал только in-app browser, прямой выбор Chrome вернул unavailable.
Это было ограничение CUA, а не доказательство недоступности стенда.

Пользователь затем прямо поручил установить Playwright MCP для Chrome.
Установлены MCP 0.0.80 и SDK 1.30.0 в `evals/.tools/playwright-mcp`, зависимости
закреплены lockfile. Обычный Codex app-server загрузил 30 инструментов сервера;
OpenViking остался подключён. Через настоящий MCP по stdio выполнены навигация,
вход, создание собственного черновика, drag узлов, открытие мастера импорта,
редактора Калькулятора и раздела «Файлы». На странице версия Loginom 7.4.2.
Диагностический Chrome имеет отдельный профиль; visible/maximized и
`viewport:null` проверены геометрией 1920×1048 outer / 1920×961 inner.
Полное чтение данных, вычисления, saved-artifact/reopen и изоляция benchmark
ещё не проверялись. Подробности:
[Playwright MCP](2026-09-10-playwright-mcp-check.md).

Официальная Help прочитана: импорт CSV имеет явный маркер Null и форматы;
выражения могут ссылаться на ранее вычисленные выражения; черновик не является
сохранённым пакетом, Save As сохраняет в выбранной директории.
