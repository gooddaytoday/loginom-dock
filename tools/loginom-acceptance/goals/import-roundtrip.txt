Проверь только настройку текстового импорта и её сохранение в узле. Это короткая диагностическая проверка участка P3, не полный выход из MVP.

Начни с dock_prepare. Доставь единственный предоставленный CSV __UPLOAD_NAME__ в __STORAGE_DIRECTORY__ через разрешённые dock_artifact_upload и dock_artifact_verify. Навигация только по свежим наблюдённым refs; scope=roots находит области, подробное чтение root_ref выдаёт действия. При большом списке используй storage_name. Загрузку выполняй во вкладке «Файлы» главного интерфейса: открой её наблюдённой кнопкой, войди в точный разрешённый каталог и проверь file_storage.status=observed и directory. Диалог выбора файла внутри мастера импорта предназначен для выбора уже загруженного серверного файла; если он открыт, отмени его и перейди во вкладку «Файлы». Только после upload/verify создавай и настраивай импорт. После отправки не повторяй upload: дождись через inspect и verify подтверждения байтов и resolved исходной операции. Разрешён replace только этого run-specific CSV.

В черновике создай один узел текстового импорта. Изучи Loginom Help integration/import/txt/README.md и E2E bg/sels/import/sImportTxt.ts, bg/sels/import/sColumnDefsTuning.ts через Dock knowledge. Выбери точный серверный файл __STORAGE_DIRECTORY__/__UPLOAD_NAME__. Установи UTF-8, заголовок в первой строке, пропуск0, разделитель ;, двойную кавычку, десятичную точку, null literal \N. Поля Id integer, Region string, Quantity integer, UnitPrice real, Comment string; все используются. После настройки формата нажми наблюдённую кнопку «Определить типы данных» один раз и дождись свежего чтения пересчитанных типов/видов и предпросмотра результата; до этого предпросмотр может показывать старое преобразование. Затем проверь все поля и исправь оставшиеся различия. Для type/kind используй select_wizard_option, если offered. После смены type проверь также data_kind. Скрытый текст ячейки не доказывает её применённое значение.

После всех изменений вернись к первой странице и сними чистое чтение wizard.import_source. Далее только wizard_step: text_import_format, чтение wizard.settings/import_columns; output_mapping, чтение wizard.output_columns; done. В каждой странице получи свежий observation. После этой исходной серии не меняй настройки. finish_wizard должен подтвердить возврат в граф. Открой тот же узел через observed body/settings и open_wizard. Повтори чтение source, format, output_mapping через wizard_step. Не исполняй узлы и не строй калькулятор/группировку; задача заканчивается сравнением этих настроек после повторного открытия. Сохранение пакета по __PACKAGE_PATH__ и полная приёмка P3 выполняются отдельно.

Не используй терминал, другой браузер, дочерних агентов или смену модели. Не считай одинаковые отдельные снимки доказательством всей последовательности: сохраняй реальные tool receipts. При отсутствии нужной возможности укажи точную наблюдаемую границу, не обходи pending и не заявляй полную готовность.
