Через Loginom Dock выполни dock_prepare, затем открой файловое хранилище и перейди в /user/data. Это чтение интерфейса перед реализацией загрузки: ничего не загружай, не создавай каталогов, не удаляй, не переименовывай, не сохраняй и не запускай узлы. Разрешены только click по кнопке файлового хранилища и double_click по каталогам user и data. Для каждого действия используй ref из доставленного наблюдения. Если нужный элемент не попал в первую страницу наблюдения, дочитай страницы по cursor.

В конечном каталоге выполни dock_workspace_observe со scope=all, без cursor и root_ref. Проверь file_storage: status=observed, directory=/user/data, source=visible_breadcrumbs, listing_complete=false. После этого не выполняй действий в браузере. Если адрес не наблюдается, сообщи это без выдумывания результата. Наличие видимых строк не доказывает отсутствие одноимённого файла во всём хранилище. Это ещё не приёмка загрузки.

При нехватке сведений используй подключённые источники E2E и Help. Работай только инструментами Loginom Dock, без терминала, другого браузера, агента или смены модели. В конце кратко сообщи наблюдаемый каталог и ограничения проверки.
